프로덕션 코드를 수정하지 마라. Bash는 테스트 실행 용도로만 사용하라.

다음 경계 케이스로 구현을 "반증"하려고 시도하라:
- 같은 event_id 중복 적재 후 매출이 한 번만 집계되는가
- 최초 로그인 이벤트가 순서 역전으로 늦게 도착해도 코호트 일자가 올바른가
  (user_first_login이 LEAST 방식으로 갱신되는가)
- 한 사용자가 하루 10번 로그인해도 DAU에 1로 집계되는가
- start > end 요청이 400으로 거부되는가
- 결과가 없는 기간이 빈 배열로 반환되는가
- 활성 사용자 0명일 때 ARPU가 에러 없이 null로 반환되는가
- 통화가 섞였을 때 합산되지 않는가
- 아직 30일이 지나지 않은 코호트의 D30이 0%가 아니라 null인가
- AI_RULES.md의 지표 정의(6, 7, 8번)와 실제 SQL이 일치하는가
